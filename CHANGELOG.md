# Changelog

## 0.1.0 (2026-11-16)

First public release.

- Swipe game with 9,595 photos from the ISIC Archive, each with a known diagnosis
- Naked eye and dermoscope modes, and a head and neck mode for barbers, hairdressers and estheticians
- Rounds of 20 photos with a summary, and a repeatable 20-photo skill check
- Notes on what the five most common diagnoses usually look like, with sources
- Spot checklist with sources
- Bold and Soft styles
- Project page, published with GitHub Pages
