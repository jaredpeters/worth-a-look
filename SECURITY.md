# Security

Worth a Look is a static web app with a small Express server. It has no accounts, stores nothing on the server, and keeps scores only in the player's browser.

## Reporting a problem

Please report security problems privately, not in a public issue: open the repository's **Security** tab and choose **Report a vulnerability**. You'll get a reply within a week.

Useful things to include: what an attacker could do, the steps to reproduce it, and the browser or setup you used.

## In scope

- The game and checklist in `public/`, the project page in `site/`, and `server.mjs`
- The build scripts in `scripts/`

Problems with the ISIC Archive itself go to the archive.
