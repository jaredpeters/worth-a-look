# Contributing

Thanks for helping. Issues and pull requests are both welcome.

## Good first contributions

- **A wrong or unclear diagnosis note.** The notes in `public/notes.js` and the checklist in `public/checklist.html` cite their sources. If something disagrees with a source, or a better source exists, open an issue with the link.
- **A photo that shouldn't be in the game**, for example one that might identify a person. Open an issue with its ISIC ID (shown on the answer card). See [RIGHTS.md](RIGHTS.md).
- **Something that feels off on a phone.** Say which phone and browser.

## Running it

```sh
npm install
npm start          # http://localhost:8140, project page at /about/
npm run check      # the checks CI runs on every pull request
```

The photo list (`public/data/deck.json`) is generated by `scripts/build_deck.py` from the ISIC Archive. Please don't edit it by hand; change the script and rebuild.

## Pull requests

- Keep each one to a single change, and say why in the description.
- Run `npm run check` before opening it.
- Medical wording is held to its source. If you change what a note or the checklist says, link the source in the pull request.
- Worth a Look stays free, non-commercial and free of tracking. Changes that add analytics, accounts or ads won't be merged.

By contributing you agree that your code is released under the [MIT license](LICENSE), and you agree to follow the [code of conduct](CODE_OF_CONDUCT.md).
